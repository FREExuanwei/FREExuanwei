## 精选项目

### [CampusFlow](https://github.com/FREExuanwei/CampusFlow)

**旗舰全栈项目** · `v0.2.0` · H2 本地演示

一个全栈校园活动管理系统，提供学生和管理员工作台。

**技术栈** · Java、Spring Boot、Spring Security、React、TypeScript、H2、Flyway

提供基于 H2 的本地演示。MySQL 生产部署仍未验证。项目自有代码采用 MIT 许可证。

<img src="https://raw.githubusercontent.com/FREExuanwei/CampusFlow/ee0df615ba526340fc170c3e480220d704aacbc5/docs/images/admin-demo.png" width="920" alt="CampusFlow 管理员工作台，使用 H2 虚构演示数据">

### [UniLife Hub](https://github.com/FREExuanwei/unilife-hub)

`0.7.0` · PWA

一个本地优先的学生效率 PWA，用于管理课程表、任务、考试和专注学习。

**技术栈** · React、TypeScript、Vite、PWA、localStorage

无需账户或云同步。仓库目前未声明通用开源许可证。

<img src="https://raw.githubusercontent.com/FREExuanwei/unilife-hub/c67f226d2cde8dcf88cbddd7d059505e2be5226b/docs/screenshots/dashboard-dark.png" width="640" alt="UniLife Hub 首页，展示虚构课表、任务和考试">

### [DevDoctor](https://github.com/FREExuanwei/DevDoctor)

[v1.2.0 发行版](https://github.com/FREExuanwei/DevDoctor/releases/tag/v1.2.0)

一个 Windows 开发环境诊断工具，支持本地历史记录、项目检查和注重隐私的报告。

**技术栈** · C#、.NET 10、WPF、MVVM、SQLite

项目自有代码采用 MIT 许可证。

<img src="https://raw.githubusercontent.com/FREExuanwei/DevDoctor/1ad648df04687522e2d84f6dac122dbf9d52cb95/docs/images/synthetic-history.png" width="640" alt="DevDoctor 诊断历史，使用合成测试记录">

### [FileFlow](https://github.com/FREExuanwei/FileFlow)

[v0.2.0-rc.2 Windows 预发行版](https://github.com/FREExuanwei/FileFlow/releases/tag/v0.2.0-rc.2)

一个支持桌面端和浏览器端的文件处理应用，提供文件转换和 PDF 工具。Windows 桌面端支持本地 OCR。

**技术栈** · React、TypeScript、Vite、Tauri、Rust

仓库未为自有代码声明通用开源许可证。
