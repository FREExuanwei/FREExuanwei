## Featured Projects

### [CampusFlow](https://github.com/FREExuanwei/CampusFlow)

**Flagship full-stack project** · `v0.2.0` · Local H2 demo

A full-stack campus activity management system with student and administrator workspaces.

**Stack** · Java, Spring Boot, Spring Security, React, TypeScript, H2, Flyway

Local H2 demo is available. MySQL production deployment remains unvalidated. The project's own code is licensed under MIT.

### [UniLife Hub](https://github.com/FREExuanwei/unilife-hub)

`0.7.0` · PWA

A local-first student productivity PWA for managing schedules, tasks, exams and focused study.

**Stack** · React, TypeScript, Vite, PWA, localStorage
